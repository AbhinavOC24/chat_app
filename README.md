# 💬 Chat App

**Chat App** is a real-time messaging application built with JavaScript and Socket.IO. It's a minimal yet functional chat platform where users can instantly connect, send and receive messages in real-time. It features custom themes, responsive UI, and instant socket communication.

---

## ✨ Features

- 📡 Real-time Messaging with Socket.IO  
- 🎨 Theme toggle with DaisyUI (Light/Dark mode and more)  
- 📱 Responsive design using Tailwind CSS  
- 🔗 Simple room-based chat interface  
- ⚙️ Built using JavaScript, Node.js, Express, and Vite  

---

## 🚀 Tech Stack

- **Frontend**: Vite + Tailwind CSS + DaisyUI  
- **Backend**: Node.js + Express + Socket.IO  
- **View Layer**: React  
- **Styling**: Tailwind CSS  
- **Realtime**: Socket.IO

## 📦 Setup & Installation

### 1. Clone the Repository

```bash
git clone https://github.com/AbhinavOC24/chat_app.git
cd chat_app
```

### 2. Install All Dependencies

Install frontend:

```bash
cd frontend
npm install
```

Install backend:

```bash
cd ../backend
npm install
```

### 3. Run the App

Start the backend server:

```bash
cd backend
npm run dev
```

Start the frontend (in a new terminal):

```bash
cd frontend
npm run dev
```

Now open your browser and visit:  
➡️ `http://localhost:5173`
